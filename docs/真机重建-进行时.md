## 本轮根因链(修了 5 个真问题)
1. **containerd config 跳过坑**: kk 角色在"二进制版本已匹配 && config_policy 为空"时跳过配置写入
   和重启 → 节点跑默认配置(sandbox=pause:3.8, root=/var/lib/containerd) → 沙箱镜像联网拉取超时
   → 产品修法: packer 发 `config_policy: overwrite`(kk 每次重写配置+重启, data_root 磁盘存储不丢)
2. **etcd library 规范化**: kubeadm 要 docker.io/etcd:v3.5.15, containerd 规范化成
   docker.io/library/etcd 再查本地 → tag 必须写 library 全称, 否则 miss 后转在线拉取
3. **flannel 镜像在 ghcr.io**: chart 0.27.4 用 ghcr.io/flannel-io/flannel:v0.27.4 +
   flannel-cni-plugin:v1.8.0-flannel1 (kk values 只覆写 repository 前缀); 之前按 docker.io 准备全白搭
4. **nodelocaldns 默认启用**: clusterDNS=169.254.25.10 → registry.k8s.io/dns/k8s-dns-node-cache:1.22.23
   必须离线导入(之前 /data1/nodelocaldns.tar 就是给它准备的)
5. **localpv 默认启用**: kk v1.28 defaults storage_class.local.enabled=true, 包内无 localpv chart
   会折在存储类步骤 → config 显式关闭 + packer 显式输出 storage_class
