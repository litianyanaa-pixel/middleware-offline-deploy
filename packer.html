1基础设置

1选择中间件 只打包勾选项, 也可接入 plugins/ 插件扩展

请先在「选择中间件」步骤勾选组件, 这里会出现端口与反代配置。

1端口映射 左侧宿主机端口, 箭头后为容器内端口; 支持追加自定义映射

2反向代理向导 域名 / 前后端转发 / 真实IP / WebSocket, 自动生成 nginx 站点配置

当前选择不需要账号密码 / 数据库配置。

1账号密码 禁止空格与 $ ` " ' \ ; | ; 部署后存于 .env (600)

2数据库来源 Nacos / XXL-Job 的建库连库方式

3数据库备份 crontab + 容器内原生工具导出, 按库分文件压缩|crontab + in-container native dump, per-DB compressed

勾选组件后, 点击下方「生成预览」查看 docker-compose / .env / manifest 最终内容; 确认无误后「开始打包」。
